# 모델링 계획: KOSPI200 종목 위험도 점수(0~100)

EDA v2(`outputs/eda_report.md`) 결과를 바탕으로 한 모델링 계획이다. 규칙은 `CLAUDE.md`와 `docs/eda_plan.md` 2절(누수 방지)을 그대로 따른다.

## 1. 목표와 출력

- **예측 대상**: 종목별 향후 5거래일 최대 낙폭 `mdd_low = min(Low[t+1..t+5]) / Close[t] − 1`(연속값, KRX 정규장 기준)
- **예측 시점**: t+1일 장 시작 전. 변수는 t일까지의 정보만 쓴다(t일 장 마감 후 공표 수급 포함).
- **출력**
  1. 예상 낙폭(%): 모델의 예측값
  2. **위험도 점수 0 ~ 100 (D 방식)**: 예측값이 학습 기간 전체 (종목, 날짜) 예측값 분포에서 차지하는 백분위
     - 점수 = 100 × P(학습 예측값 ≥ 오늘 예측값). 예측 낙폭이 클수록(더 음수일수록) 점수가 높다.
     - 환산표(분위 경계)는 학습 구간의 **교차검증 예측값(out-of-fold)**으로 만들고 고정한다. 검증 구간과 운영에서는 이 표를 그대로 쓴다.
     - 위험한 시기에는 전 종목의 점수가 함께 오른다. 그날 순위가 아니라 **과거 대비 수준**을 뜻한다.

## 3. 변수 세트

`feature_candidates.csv`의 강력 추천과 검토 변수에서 중복을 줄여 시작한다. **순위 버전(`_rk`)이 아니라 원래 값을 쓴다.** 원래 값에 시장 전체 수준 정보(예: 변동성이 큰 장에서는 모든 종목의 `gk_5`가 오른다)가 담겨 있기 때문이다.

| 역할 | 후보 (초기 세트) |
|---|---|
| 변동성(1~2개) | `gk_5`, `idio_vol_60` |
| 하방 특성 | `skew_60`, `past_mdd_60`, `n_down3_60`, `downside_ratio_20`, `min_intra_drop_20` |
| 가격 위치·모멘텀 | `dist_low_60`, `pos_20`, `ret_20`, `|ret_20|`(U자 관계 대응) |
| 유동성·규모 | `turnover_20`, `log_mcap`, `vol_ratio_20_60` |
| 시장 민감도 | `beta_60` |
| 신용·대차·수급 | `margin_rate`, `lend_days_20`, `pension_net_20`, `indiv_net_20`, `prog_nonarb_net_20`, `foreign_hold` |
| 업종 | `ind_vol_20` |
| 시장 공통 | `mkt_vol_20`, `mkt_ret_20`, `mkt_ret_60`, `cs_dispersion_1`, `breadth_adv_5`, `mkt_institution_net_20` |

- 결측(신규 상장 60일 미만, 폐지·합병 3종목의 수급)은 트리 모델에서는 그대로 두고, 선형 모델에서는 그날 중앙값으로 채운 뒤 결측 플래그를 붙인다.
- 공매도 변수는 체제가 바뀌므로(2025-03-31) 초기 세트에서 빼고, 추가 실험으로만 확인한다.

## 4. 검증 설계 (학습 구간 안)

- **시간 순서 교차검증**: 학습 구간을 날짜 블록 5개로 나누고, 앞 블록으로 학습해 다음 블록을 예측한다(확장 창).
  - 블록 경계 앞뒤 5거래일은 학습에서 뺀다(purge). 타깃 구간이 겹치기 때문이다.
  - 마지막 블록에는 2026년 상반기 고변동 국면이 들어간다. 이 블록 성능을 따로 보고한다.
- **하이퍼파라미터**는 교차검증 평균으로 고른다. 검증 구간은 쓰지 않는다.

## 5. 베이스라인과 모델

| 이름 | 내용 | 목적 |
|---|---|---|
| B0 | 학습 구간 평균 MDD_5(상수) | 최소 기준 |
| B1 | 예측 = a + b × `gk_5` (선형) | "변동성 하나로 충분한가" 기준 |
| M1 | 규제 선형회귀(Ridge/Huber) + U자 변환 | 해석 가능한 모델 |
| M2 | LightGBM 회귀(손실: L2와 Huber 비교) | 비선형·상호작용 |

- 복잡한 모델은 B1을 분명히 넘을 때만 채택한다.
- 필요 패키지: `lightgbm`, `scikit-learn`(설치 후 `requirements.txt`에 기록)

## 6. 평가 지표

| 관점 | 지표 | 뜻 |
|---|---|---|
| 순위 | 날짜별 IC 평균·IR | 같은 날 어느 종목이 더 위험한지 맞히는가 |
| 수준 | 날짜별 평균 예측 vs 실제 평균의 상관, 평균 오차 | 시장 전체 위험 수준을 따라가는가 |
| 오차 | MAE, RMSE | 예상 낙폭이 얼마나 정확한가 |
| **점수 신뢰성** | 점수 구간(0~10, …, 90~100)별 실제 평균 MDD_5와 -10% 이상 하락 비율 | 점수가 높을수록 실제로 더 빠지는가(단조성), 환산표의 %와 맞는가 |
| 안정성 | 블록별·반기별 위 지표, 2026H1 별도 | 국면이 바뀌어도 유지되는가 |

## 8. 주의점 (EDA에서 나온 것)

- **시장 수준은 예측이 어렵다.** 점수의 날짜별 수준 변화는 종목 간 순위보다 부정확할 것이다. 평가에서 두 가지를 분리해 보고한다.
- **검증 구간은 2026년 상반기 충격 국면 직후다.** 학습 기간 평균과 수준 차이가 클 수 있다.
- **분포가 한쪽으로 치우쳐 있다.** 타깃은 왼쪽 꼬리가 두껍다(왜도 -1.7). L2 손실은 극단값에 끌려가므로 Huber 손실과 비교한다.
- **환산표의 해석**: 점수는 확률이 아니다. 리포트와 화면에는 "점수 90 = 학습 기간 예측값 중 상위 10% 위험, 예상 낙폭 약 X%" 형태의 환산표를 함께 둔다.
