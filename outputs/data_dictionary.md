## 3. 종목 코드 체계

- 모든 종목 테이블은 `symbol varchar(20)`을 쓰며, 실제 값은 **6자리 KRX 단축코드**다. 앞자리 0이 있으므로 문자열로 다뤄야 한다(정수 변환 금지).
- 대부분 숫자 6자리지만, 2025년 이후 신규 상장 종목은 영문이 섞인 새 코드 체계를 쓴다: `0126Z0` 삼성에피스홀딩스(2025-11-24 상장), `0220W0` 한화머시너리앤서비스홀딩스(2026-08-25 상장). 숫자만 가정한 정규식이나 정수 변환은 이 종목들을 깨뜨린다.
- `stocks.isin_code`는 230개 모두 `KR7` + 단축코드 형식이다.
- 지수·금리 테이블은 종목 코드가 아니라 이름을 쓴다: `KOSPI`, `KOSDAQ`, `KR_BOND_{2Y,3Y,5Y,10Y,20Y,30Y}`.
- 종목 테이블 사이의 조인 키는 `(symbol, trade_date)`이며, 세부 분류 테이블은 `category`까지 포함한다.

## 3.1 `krx_daily_candles` (v2, 2026-09 적재)

KRX 정규장 일봉. 사용자가 KRX에서 받아 DB에 적재했다(주 가격 원천).

| 컬럼 | 설명 |
|---|---|
| symbol, trade_date | 기본키. 232종목(`kospi200_membership`에 나온 모든 종목), 660거래일(2024-01-02 ~ 2026-09-16), 149,961행 |
| open/high/low/close_price | **정규장** 수정주가(분할·병합·무상증자·주식배당·권리락·인적분할 반영) |
| volume, trading_value | 수정 거래량, 거래대금(원). 시간외 거래 포함 여부는 구분할 수 없다 |
| raw_open/high/low/close, raw_volume, base_price, adj_factor | 원주가, 기준가, 날짜별 수정계수 |
| listed_shares | 그날의 상장주식수(시점별 값) → 회전율·시가총액 계산에 쓴다 |
| halted | 거래정지 여부. 정지일은 O=H=L=C=종가로 채워져 있다 |

검증(`03b_krx_validation.ipynb`): NXT 이전은 기존 일봉과 가격 차이가 최대 0.035%다. NXT 이후 저가 스파이크는 90건에서 2건으로 줄었다. 수정 후 하루 ±30.5% 초과 수익률은 0건이다. 폐지·합병 3종목은 마지막 거래일(003410 2024-07-08, 010620 2025-12-12, 042670 2026-01-23)까지 있다. 코스닥에서 옮겨 온 034230, 066970은 이전일부터만 있다.

## 4. 테이블별 컬럼

공통 메타 컬럼 `collected_at`은 수집 시각이므로 변수로 쓰지 않는다. `updated_at`은 원천 데이터가 마지막으로 갱신된 시각으로 보이며, 공표 시차를 추정하는 데만 쓴다(5절).

### 4.1 `stock_daily_candles` (핵심)

| 컬럼 | 타입 | NULL | 설명 / 비고 |
|---|---|---|---|
| symbol | varchar(20) | N | 종목 코드 |
| trade_date | date | N | 거래일 |
| open_price, high_price, low_price, close_price | decimal(20,4) | N | 시가·고가·저가·종가 |
| volume | decimal(20,0) | N | 거래량. **거래대금 컬럼은 없다**: 거래대금은 종가×거래량으로 근사해야 한다 |
| currency | varchar(10) | N | 모두 `KRW` |
| adjusted | tinyint(1) | N | 모두 1(수정주가라고 표시됨). 실제로 수정됐는지는 Step 2에서 분할 시점의 비정상 점프로 확인한다 |

- 230개 종목의 전체 기간 일봉이 있다. 여기에는 구성종목에 한 번도 들지 않은 `010170`(대한광통신, KOSDAQ)이 포함되고, 이 종목의 `is_kospi200`은 항상 0이다.
- 학습 구간 일자별 `is_kospi200=1` 종목 수는 197(121일), 198(283일), 199(82일), 200(120일)이다. 200개에 못 미치는 것은 1절 #2의 누락 3종목 때문이다.

| `market_indicator_investor_trading` | {individual, foreigner, institution, other_corp}_{buy, sell}_amount | 원 | 시장 단위(KOSPI, KOSDAQ) |
| `market_institution_breakdown` | category(7종), buy/sell_amount | 원 | 시장 단위 |

종목 단위 수급은 **수량** 단위이고 시장 단위는 **금액** 단위다. 종목 간에 비교하려면 거래량이나 발행주식수로 정규화해야 하는데, 발행주식수는 현재값뿐이다(4.3). 따라서 거래량 대비 비율을 기본으로 한다.

## 5. 공표 시차와 누수 위험

**시차 규칙 (결정됨, 2026-09-28)**: 모델은 t+1일 장 시작 전에 예측한다. t일 장 마감 후 공표되는 데이터는 추가 lag 없이 t일 변수로 쓴다. 따라서 점검 기준은 "**원천 갱신 시각(`updated_at`)이 t+1일(다음 거래일) 09:00 이전인가**"다.

점검 방법과 한계:
- 모든 테이블의 `collected_at`(DB 적재 시각)은 2026-09-16~17 하루에 몰려 있다. 과거 데이터를 한꺼번에 소급 적재했기 때문에, **DB 적재 시각으로는 실시간 입수 가능 여부를 판단할 수 없다.** 그래서 원천 갱신 시각인 `updated_at`을 기준으로 삼았다.
- `updated_at`은 **최종** 갱신 시각이다. 이 값이 t+1일 09:00 이후라면, DB에 저장된 값이 예측 시점 이후에 수정된 값일 수 있다(값이 실제로 바뀌었는지는 알 수 없다).
- 다음 거래일은 `stock_daily_candles`의 거래일 캘린더로 정했다. 점검 대상은 학습 구간(2024-01-01 ~ 2026-06-30) 전체다.

| 테이블 | 주된 갱신 시점 | t+1일 09:00 이후 갱신 행 | 판정 |
|---|---|---|---|
| `stock_daily_candles` | – | – | t일 장 마감으로 확정 |
| `stock_short_selling` | t일 18:13경 (100%) | 0건 | 문제 없음 |
| `market_indicator_investor_trading` | t일 18:06~20:02 (100%) | 0건 | 문제 없음 |
| `stock_investor_trading` | t+1일 06:50경 | **693건 (0.50%), 7일** | 대부분 문제 없음. 예외 일자 있음 |
| `stock_credit_trades` | t+1일 04:00경 | **229건 (0.17%), 2일** | 대부분 문제 없음. 예외 일자 있음 |
| `stock_securities_lending` | t일 19:00경. 금요일분은 일요일 19:00 | **32,129건 (23.3%), 144일** | **2024-01-02 ~ 07-31 전체가 문제** |
| `stock_program_trades` | `updated_at` 없음 | 확인 불가 | 확인 불가 |
| `stock_institution_breakdown`, `market_institution_breakdown` | `updated_at`·`collected_at` 없음 | 확인 불가 | 확인 불가 |

t+1일 장 시작 전에 확정되지 않은 사례:
1. **`stock_securities_lending`, 2024-01-02 ~ 2024-07-31 (144거래일, 32,129행 전부)**: 모두 2024-08-08에 일괄 재갱신됐다. 분석 표본(2024-04-01~)과 겹치는 기간은 2024-04-01 ~ 07-31(약 4개월)이다. 2024-08 이후에는 t+1일 09:00 이후 갱신이 0건이다.
2. **`stock_investor_trading`**:
   - 2024-01-02, 01-03: 각각 198행이 2024-01-15에 재갱신됐다(워밍업 기간이라 표본 영향은 롤링 변수뿐).
   - 2025-08-19: 183행이 2025-08-27에 재갱신됐다.
   - 2026-04-16: 56행이 2026-04-18(토) 09:39에 재갱신됐다.
   - 2026-04-21: 56행이 2026-04-22 09:00 이후에 갱신됐다.
   - 2026-01-15, 01-16: 각 1행.
3. **`stock_credit_trades`**: 2025-08-19의 228행이 2025-08-27에 재갱신됐다(투자자별 매매와 같은 날). 2025-12-11에 1행이 더 있다.
4. **`stock_program_trades`와 기관 세부 테이블 2개**는 갱신 시각 컬럼이 없어서 확정 시점을 검증할 수 없다. 투자자별 매매와 같은 계열의 데이터라 t일 저녁에 공표된다고 보지만, 이는 데이터로 확인한 사실이 아니라 가정이다.

처리 방침(eda_plan 2절에 반영): 늦게 갱신된 행은 제외하지 않고 플래그(`late_update`)를 단다. 해당 테이블에서 만든 변수는 이 행을 뺀 결과로도 결론이 유지되는지 확인한다. 대차 변수는 2024-08 이후 표본만으로 따로 확인하는 것을 권장한다.

기타 누수 위험:
- `stocks.shares_outstanding`, `stocks.status`는 현재값이므로 과거 시점 변수로 쓰면 안 된다.
- `is_kospi200`, `kospi200_membership`: 스냅샷이 소급 수집됐으므로, 원천이 진짜 당시 시점(point-in-time) 명단인지 Step 1에서 알려진 정기변경 시점과 대조한다.
- 모든 롤링 통계는 과거 방향으로만 계산한다. 워밍업 이전 값을 앞쪽 값으로 채우지 않는다.

## 6. 결정이 필요한 사항

1. ~~워밍업 부재 대응~~ → **결정됨 (2026-09-28)**: 과거 데이터는 추가하지 않는다.
   - 변수의 롤링 윈도우는 **최대 60거래일**이다. 워밍업이 61거래일이므로, t일 이전에 필요한 거래일 수(lag와 중첩 롤링 포함)는 61일 이하여야 한다. 예를 들어 수급 lag 1 + 60일 롤링은 가능하고, 20일 변동성의 60일 변화율(80일)은 불가능하다.
   - 분석 표본은 **2024-04-01부터** 시작한다. 그 전 61거래일(2024-01-02 ~ 03-29)은 워밍업 전용이다. 따라서 2024-04-01에 60일 수익률과 60일 변동성(수익률 60개)을 모두 계산할 수 있다.
   - 학습 표본은 2024-04-01 ~ 2026-06-30, 545거래일이다(기존 606일에서 61일 줄어듦).
   - eda_plan의 120일 수익률, 52주(250일) 고점·저점 위치 같은 변수는 만들지 않는다. 대체 변수는 60일 고점·저점 위치 등으로 한다.
2. ~~장 마감 후 공표 데이터의 lag 규칙~~ → **결정됨 (2026-09-28)**: 예측은 t+1일 장 시작 전에 한다. t일 장 마감 후 공표 데이터는 lag 없이 t일 변수로 쓴다. 타깃은 `min(Low[t+1..t+5]) / Close[t] - 1`을 유지하며, t+1일 시가 갭 하락을 포함한다. 갱신 시각 점검 결과는 5절에 있다.
3. ~~누락 3종목~~ → **결정됨 (2026-09-28)**: 003410, 010620, 042670은 분석에서 제외한다. 학습 구간 (날짜, 구성종목) 1,072쌍(0.88%)이 빠지며, 이로 인한 생존 편향 가능성은 최종 리포트의 한계 항목에 적는다.
4. ~~시장 지수~~ → **결정됨 (2026-09-28)**: 시장 요인(시장 수익률·변동성, 베타, 초과수익률)은 `market_indicator_daily_candles`의 `KOSPI` 종합지수로 계산한다.

5. **정기변경 반영 시차 (Step 1)** → **결정됨 (2026-09-28)**: 월초 스냅샷을 그대로 쓴다. 정기변경 효력일(추정)부터 스냅샷 반영 전까지의 46거래일에는 `rebal_gap_day` 플래그를 단다. 이 구간에서 실제로 틀릴 수 있는 쌍은 592개(0.55%)다.
6. **주 타깃 (Step 3)** → **결정됨 (2026-09-28)**: `mdd_low_clean`(저가 기준, 비정상 저가 보정). KRX 단독 시세를 확보하면(데이터 제공처 확인 중) 원본 저가 기준 `mdd_low`로 교체한다.
7. **타깃 양수 값 (Step 3)** → **결정됨 (2026-09-28)**: 0으로 자르지 않고 원래 값 그대로 쓴다.

9. **가격 원천 교체 (v2)** → **결정됨 (2026-09-28)**: KRX 정규장 일봉 `krx_daily_candles`를 쓴다. 주 타깃은 `mdd_low`로 되돌리고, 스파이크 보정을 끈다. 3종목 제외를 풀었다.
